# One spot colour per page, chosen per essay in frontmatter

Each page carries exactly one spot colour. An essay may set its own with an optional `spot` hex in its frontmatter; otherwise the house terracotta applies. The dark-scheme rendition and the darker text rendition are both derived from that one hex, never hand-picked, so a single value recolours the whole page in both schemes. The only place two spots meet is the essays list, where each entry's rule carries its own essay's spot. Decided 2026-09-22.

## Considered options

- One fixed house colour. Rejected: a magazine program gives each issue its own spot, and the per-piece choice is part of shipping an essay.
- Hand-picked light and dark pairs per essay. Rejected: two values to keep in step per essay, and a contrast check per pair. Deriving both from one hex keeps publishing cheap.

## Consequences

- Choosing a spot is part of publishing an essay, alongside the description and the date.
- The spot appears only as rules, the drop initial, the closing square, the current-page dot, and link ink. It never fills a surface and never sits behind text.
